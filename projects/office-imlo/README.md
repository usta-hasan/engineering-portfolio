# Office Imlo

A Windows tool for Uzbek text normalization and Latin/Cyrillic transliteration in Word, Excel, PowerPoint, Visio, Project and classic Outlook. Word also includes a booklet page calculator. The implementation uses VBA and C# COM integration. Public release v3.1.2 exists. Use the existing Office-Imlo repository for installation instructions; developer backups and signing material are not distributed here.

## O‘zbekcha tavsif

Office hujjatlarida o‘zbekcha belgilarni me’yorlashtirish, yozuvni almashtirish va kitobcha chop etish hisobini soddalashtirish.

Word uchun VBA, boshqa qo‘llab-quvvatlangan Office dasturlari uchun COM integratsiyasi, Windows o‘rnatuvchisi va yangilash tizimi.

**Texnologiyalar:** C#, .NET Framework, VBA, COM, Word, Excel, PowerPoint, Visio, Project, klassik Outlook.

**Algoritm:** Matn yoki tanlangan obyekt → belgi/yozuv almashtirish → natijani hujjatga qaytarish. Word kitobcha hisoblagichi chop etish uchun betlar tartibini hisoblaydi.

**Shaxsiy hissa:** Dastur va foydalanuvchi ish jarayonini ishlab chiqish, Office integratsiyasi, interfeys va tarqatish; AI yordamida amalga oshirilgan iteratsiyalar mavjud.
